# 📬 Formulário de Contacto com Validação

Este é um projeto simples de um formulário HTML com validação de **email** e **telefone** usando **JavaScript**. O objetivo é demonstrar como validar dados do utilizador antes do envio, com foco na usabilidade e boas práticas.

---

## 🛠️ Tecnologias Utilizadas

- ⚙️ **HTML5** – estrutura do formulário
- 🎨 **CSS3** – estilo básico para melhor visualização
- 🧠 **JavaScript** – validação dos campos de email e telefone

---

## ✨ Funcionalidades

- Validação de email com expressão regular
- Validação de número de telefone  (prefixos +55-99 )
- Exibição de mensagens de erro 
- Estilo limpo e responsivo
